#### 1. Standardize JSON Responses (`app/schemas/base.py`)


#### 2. Main Application Assembly (`app/main.py`)

Initialize the FastAPI application and configure the server:

* **CORS Middleware:** Add `CORSMiddleware` with `allow_origins=["*"]`, `allow_credentials=True`, `allow_methods=["*"]`, `allow_headers=["*"]` so the local HTML/CSS dashboard can make requests without blocking.
* **Router Inclusion:** Import and `include_router` for all sub-routers:
* `api.ingestion.router` (prefix: `/api/batch`)
* `api.reconciliation.router` (prefix: `/api/reconciliation`)
* `api.exceptions.router` (prefix: `/api/exceptions`)
* `api.copilot.router` (prefix: `/api/copilot`)
* `api.forecasting.router` (prefix: `/api/forecast`)
* `api.audit.router` (prefix: `/api/audit`)


* **Health Check Endpoint:** Add a basic `GET /health` route verifying database connectivity and LLM worker status.

#### 3. Execution Entry Point (`run.py`)

Create a simple top-level script using `uvicorn.run("app.main:app", host="0.0.0.0", port=8000, reload=True)` to easily start the backend server.

#### 4. The E2E Benchmarking Script (`scripts/benchmark_e2e.py`)

This is the script you will run live or record for the judges to prove your prototype clears "The Bar". Write an async Python script using `httpx` to simulate a complete finance-ops loop programmatically:

1. **Start Timer:** Initialize `time.perf_counter()`.
2. **Ingest Data:** Call `POST /api/batch/generate-synthetic` to create and ingest the 50+ record batch. Extract the `batch_id`.
3. **Run Reconciler:** Call `POST /api/reconciliation/run/{batch_id}`.
4. **Fetch Summary:** Call `GET /api/reconciliation/summary/{batch_id}` and assert that `total_records >= 50`.
5. **Fetch Exceptions:** Call `GET /api/reconciliation/exceptions/{batch_id}` and assert that the exception list is not empty (proving the "honest exception list" requirement).
6. **Fetch Audit Trail:** Call `GET /api/audit/trail/{batch_id}` to verify immutability.
7. **Stop Timer & Print Report:** Calculate total end-to-end execution time. Print a heavily formatted CLI report (using rich or standard ANSI colors) showing:
* Total Execution Time (Must be < 5.0 seconds).
* Match Rate Percentage.
* High Risk vs. Low Risk Exception Breakdown.
* Example 1-Click Action generated by the AI.
